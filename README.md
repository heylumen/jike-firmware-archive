## 三、固件文件命名规则

| 标识 | 含义 |
|---|---|
| `EPORT` | 有线网口支持**扩展 VLAN** |
| `LLELL` / `LLLLW` | 5 个有线口的顺序标识：`L`=上联口（通所有 VLAN）、`E`=扩展 VLAN 口（只通对应 VLAN，不带标签） |
| `FREE` | 该 AP 支持**免注册**（免费版） |
| `JIKEAP_` | 测试版固件（源站 apbeta 测试版库） |
| `GECOOS_` | 正式版固件（源站首页正式版库，含 MD5） |

> ⚠️ **扩展 E 口防 DHCP 反接**（默认获取不到 IP、过滤 VLAN）——**切勿用 E 口作上联口**接上级路由或交换机。

## 五、存放方式

固件本体以 **Release 资产**形式存放（不占用仓库体积），提供**两种下载方式**：

1. **单文件（按型号取用）**：每个型号一个 `single-<型号>` Release，内含该型号全部固件的裸文件，按文件名（含版本日期）直接下载，无需解包；型号索引见 [`SINGLE_FILE_INDEX.md`](SINGLE_FILE_INDEX.md)。
2. **整包 zip（批量收藏）**：按发布批次目录打包，store 不压缩；仅 `2026_20260920` 批次因 2.32 GB 超单资产 2 GiB 上限改用 deflate（解压后目录结构不变）。

两种方式内容一致，按需选择。

| Release | 内容 | 资产数 |
|---|---|---|
| `2026-09-20` | 整包基线（2018-07 ~ 2026-10-25 批次，4035 文件 / 36.55 GB） | 50 |
| `2026-11-01` | 整包增量（`20261025`/`20261026`/`20261030` 三批次，215 个 / 2.46 GB） | 3 |
| `single-<型号>` × **265** | 单文件（每型号一个 Release，裸文件可直接下载；同名多版本按 `原名__<批次日期>` 命名；索引见 `SINGLE_FILE_INDEX.md`） | **4048**（合计，覆盖 4035 个文件） |

> 合计 **267 个 Release** = 265 个单文件 + 2 个整包。

**命名规则**：资产名 = `<年份>_<发布日期>.zip`（如 `2024_20240810.zip`）；
单批超 1.45 GB 时拆包，追加 `_partN`（如 `2026_20260915_part1.zip`、`router_part1.zip`）。
zip 内**保留完整中文相对路径**，解压即还原目录结构。

## 七、如何还原

1. 下载所需批次的 zip；
2. 解压到归档根目录（保持包内相对路径）；
3. 用 `MANIFEST.csv` 的 MD5 逐个校验完整性。

`MANIFEST.csv` 字段：`相对路径, 文件名, 大小(字节), MD5, 年份, 批次, 分类`

## 十、备注

- 打 **store（不压缩）** 模式：固件多为已压缩/加密格式，压缩无收益。
- **源站不是蓝奏云的超集**：实测部分固件（如 RK3568 平台 AC 控制器、网关 2026-02 版）仅见蓝奏云渠道。
- **蓝奏云部分历史分类已下架**，本归档可能是这些版本的完整副本。
- 源站会**以新版替代旧版**而非补传：若某版本在源站消失，不代表其从未存在。

### 常见问题（摘自社区）

- **AP 显示"未注册"**：使用非官方设备时的正常标识，不影响功能。集客已开放固件，微 AC 等功能均可使用。
- **AP 是否支持中继**：不支持。需要中继请用「集客无线神器」固件。
- **漫游阈值**：微 AC 下设置无效；无 AC 时阈值同样不生效。有 AC 时为**主动漫游**，效果优于弱踢。
- **MTK 设备漫游不积极**：可尝试关闭 KVR（仅禁用 R），对智能设备更友好。
- **定时重启**：设计为「无用户连接时重启」或「凌晨 4–5 点错峰重启」，不支持指定时刻（避免千台设备同时重启）。
